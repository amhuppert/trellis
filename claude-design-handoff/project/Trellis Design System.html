Engine · packages/engine/design-tokens v0.1 · derived from Modular Bento

The design system for agent-authored, navigable reports.

A constrained vocabulary of color, type, space, and shape — declared once as CSS variables, surfaced to authors as a thin layer of semantic Tailwind utilities, and assembled into the component library that every Trellis report inherits.

01Principles

Five commitments the rest of the spec follows from. Each is a constraint on what the system says yes to and — more importantly — what it refuses to expose.

One palette, named
Authors never reach for bg-blue-500. The class doesn't exist. Color is requested by role — bg-surface, text-accent — and the role decides the hex.
Type is roles, not sizes
Size, weight, leading, and tracking ship together as a single text-h2 or text-body. Vertical rhythm is the system's job, not the author's.
Components carry the load
90% of authoring is composing <Callout variant="info">, not assembling utility strings. Tailwind is the floor; the library is the room.
Dark mode is free
Semantic tokens flip values under .dark. Components don't need dark: variants for color — they get parity for nothing.
One source of truth
Tokens declared in design-tokens/ emit both Tailwind theme extensions and CSS variables, so utilities and inline SVG fills read the same value.
Refuse, don't extend
When something doesn't fit, the answer is a component or a justified custom/ escape hatch — not a new color, font, or spacing value.

06Elevation

Two shadows, no third. Trellis surfaces sit flat against the page; elevation appears only when something is genuinely floating (hover-card, focused dropdown). Borders carry the rest of the depth signal.

none · resting
Cards, blocks, nav rows.
shadow-sm
Top bar on scroll, sticky surfaces.
shadow-pop
EntityRef hover-card, dropdown menus.
There is no shadow-md or shadow-lg. If a surface needs to feel higher than none but isn't floating, the answer is a border-border or a switch to bg-surface-2, not a new shadow.
07Motion

Motion is for confirming continuity, not commanding attention. Three durations and one easing curve cover the system.

TokenDurationUsed for
--motion-fast120msHover state changes, color flips, button presses.
--motion-med220msView enter, panel slide-in, pagination "next" lean.
--motion-slow360msGraph layout transitions, focus-to-spotlight.
--ease-outcubic-bezier(.2, .7, .3, 1)Single curve for the whole system. No bounces, no springs.
Two named keyframes are exposed: animate-view-enter (fade + 4 px lift, --motion-med) for route transitions, and animate-pop-in (fade + scale 0.98→1, --motion-fast) for popovers. Other animations are component-local and must stay within these durations.

10cn() & class-variance-authority

Two helpers bridge "utility soup" and "typed components". Every component in the engine uses both.

cn() — merge utilities, resolve conflicts
// packages/engine/utils/cn.ts import { clsx, type ClassValue } from "clsx"; import { twMerge } from "tailwind-merge"; export function cn(...inputs: ClassValue[]) { return twMerge(clsx(inputs)); }
cva() — the variant table for a component
// packages/engine/components/content/Callout.tsx import { cva, type VariantProps } from "class-variance-authority"; import { cn } from "@engine/utils/cn"; const callout = cva( "grid grid-cols-[28px_1fr] gap-3 rounded-2xl px-5 py-4 border border-border-soft", { variants: { tone: { info: "bg-sage-bg [&_.glyph]:bg-sage", warn: "bg-coral-bg [&_.glyph]:bg-coral", aside: "bg-butter-bg [&_.glyph]:bg-butter-ink", quote: "bg-surface [&_.glyph]:bg-ink", }, }, defaultVariants: { tone: "info" }, } ); type Props = VariantProps<typeof callout> & { title: string; children: React.ReactNode; className?: string; }; export function Callout({ tone, title, children, className }: Props) { return ( <aside className={cn(callout({ tone }), className)}> <div className="glyph grid place-items-center w-6 h-6 rounded-full text-bg font-serif text-label font-bold">?</div> <div> <div className="text-label font-bold text-coral">{title}</div> <div className="text-body mt-1">{children}</div> </div> </aside> ); }
Authors never look inside this file. They call <Callout tone="warn" title="...">. The variant table is the only place tone-to-class mapping lives, and Storybook exposes every combination by enumerating VariantProps.

12Content blocks

The teaching components — each is a fixed recipe of card + accent + type roles. The agent picks the block by pedagogical intent; the recipe locks the visual treatment.

ConceptIntro · concept
Concept · introducing
What's the problem MVCC is solving?
A database is a single, shared piece of state. The moment two clients are reading and writing at the same time, the system has to decide whose view of the world is real. Locking is one answer. MVCC is a different one — one that lets readers and writers stop blocking each other entirely.
Card · accent="coral" · 4px left border · serif body 18/1.62.
MentalModel · sage tint
Mental model
The mental model in one sentence
Each transaction reads from its own snapshot of the database — a frozen moment that ignores anything that hasn't committed yet, and ignores anything that committed after the snapshot was taken.
If you remember nothing else from this report, remember this: a Postgres reader never sees a half-written world.
Card · tone="sage" · sans-serif italic aside under hairline rule.
Callout · three tones
i
Why not just lock?
In a lock-based system, a read takes a shared lock and a write takes an exclusive lock. They wait on each other.
!
Where this stops being safe
Snapshot isolation is not serializable. Two transactions reading and writing disjoint rows can still produce a state that no serial schedule could.
·
Aside
Postgres calls these snapshots "MVCC snapshots" internally, but the same idea exists in SQL Server's RCSI and Oracle's read-consistency.
tone = info (sage) · warn (coral) · aside (butter). Glyph color matches accent.
KeyTakeaways · inverted slab
Key takeaways
  • An UPDATE never overwrites — it stamps the old row and appends a new one.
  • The snapshot, not the row, decides what a transaction sees.
  • VACUUM is the only thing standing between live snapshots and disk pressure.
Card · surface="ink" · coral eyebrow + dashes · serif body 17/1.45 in bg color.
CommonMisconception · coral tint
Common misconception
"MVCC means writes are free — Postgres just appends a new row."
ActuallyEvery update doubles the row's physical footprint until VACUUM catches up, and the old tuple's xmax write is a real disk write too.
Card · tone="coral" · italic claim · inset "Actually" panel on surface.

Validation hooks
The build runs three checks beyond the Zod schemas:
  • Tailwind's forbid-arbitrary-values plugin scans every emitted class against the four locked categories.
  • A lightweight import scan in reports/<name>/custom/ ensures only @engine/* and standard libraries are imported. [V1.x — opt-in in V1.]
  • Storybook story coverage: every exported component must have at least one story; CI fails otherwise.
